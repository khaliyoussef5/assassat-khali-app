# خطة التطوير

1. حفظ حاسبة Armstrong V1.4 واختبار الحسابات والنشر برابط ثابت.
2. إضافة Armstrong بلا بوردور، بصفوف مقطوعة متوازنة ودعم الحواف.
3. إضافة سقف BA13 عادي وسقف إنارة مخفية حسب قواعد Fourrure.
4. إضافة الحوائط: Cloison، Doublage، Montants، Rails، Rockwool والفتحات.
5. جمع عدة غرف/حوائط في مشروع واحد مع PDF واحد شامل.

## سياسة النشر
فرع جديد لكل تعديل → اختبار تلقائي → رابط تجريبي → موافقة المستخدم → دمج main → نشر تلقائي.
لا تُغيّر قواعد Armstrong القائمة من غير طلب صريح واختبارات مرجعية.
